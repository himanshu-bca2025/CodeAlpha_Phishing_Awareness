## 📖 Project Overview

In today's digital landscape, human error remains one of the most significant vulnerabilities in cybersecurity. This **Phishing Awareness Training Module** is a fully interactive front-end web application designed to educate users on the dangers of phishing and social engineering. 

Developed as **Task 2** for the **CodeAlpha Cyber Security Internship**, this project bridges the gap between theoretical security concepts and practical threat recognition through a guided, slide-by-slide learning experience followed by a dynamic knowledge assessment.

## 🎯 Learning Modules Covered

The training program is divided into structured sections to provide a comprehensive understanding of phishing threats:

1. **Understanding Phishing:** Defines the core concept of phishing, exploring how attackers disguise themselves as trusted entities to steal sensitive credentials.
2. **Threat Recognition:** Provides actionable techniques to identify fake URLs, spot spoofed email addresses, and recognize the psychological triggers (like false urgency) used by scammers.
3. **Social Engineering Tactics:** Explains how cybercriminals exploit human emotions—such as fear, greed, and curiosity—to bypass logical thinking and security protocols.
4. **Defense Mechanisms & Best Practices:** Outlines standard security protocols for end-users, including the importance of Two-Factor Authentication (2FA), direct URL navigation, and verifying sender identities.

## ✨ Technical Features

- **Interactive Presentation UI:** Built with a custom slide-navigation system that mimics professional presentation software.
- **Staggered Animations:** Utilizes CSS `@keyframes` to create smooth, point-by-point text rendering, ensuring the user is not overwhelmed with information all at once.
- **Dynamic Quiz Engine:** A 5-question interactive assessment built with Vanilla JavaScript.
- **Real-time Feedback System:** Instantly evaluates user input upon submission, locking the form to prevent cheating, and displaying detailed explanations for both correct and incorrect answers.
- **Fully Responsive Single-Page Architecture:** The entire training module, including styles and logic, is efficiently contained within a single `index.html` file for seamless deployment and zero-dependency execution.
